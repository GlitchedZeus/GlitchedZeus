## Hey, I'm GlitchedZeus

I started programming in **2026** to make an app for my own Switch. The side project turned into a fascination with Pokémon save data, homebrew UI, emulator compatibility, and getting things right on real hardware.

I'm still learning. I like straightforward code, controller-friendly interfaces, and protecting the original save before touching anything.

## Open-source contributions

I contribute to <a href="https://github.com/kiasta/PKSE"><b>PKSE</b></a>, a Nintendo Switch Pokémon save editor. Two features were merged upstream and credited in the <a href="https://github.com/kiasta/PKSE/releases/tag/v1.2.1">official v1.2.1 release</a>.

| Contribution | What changed |
| :-- | :-- |
| <a href="https://github.com/kiasta/PKSE/pull/120"><b>PR #120 · Left-stick navigation</b></a> | Analog stick and D-pad parity, with held-repeat and input handling across the UI. |
| <a href="https://github.com/kiasta/PKSE/pull/128"><b>PR #128 · Pokémon file import/export</b></a> | Standalone Pokémon file support, PKHeX-compatible serialization, and safer Bank imports/exports. |

The working fork is <a href="https://github.com/GlitchedZeus/PKSE-Zeus">PKSE-Zeus</a>.
