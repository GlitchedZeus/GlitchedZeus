## About

I'm a homebrew hobbyist who started programming in 2026. What began as a spare-time Switch project turned into an interest in C++ applications, Pokémon save formats, emulator compatibility, and testing software on real hardware.

I care about **controller-first interfaces, safe save handling, accurate data formats, and changes that are actually tested**.

## Projects

| Project | Description | Status |
| --- | --- | --- |
| **[PokeBank NX](https://github.com/GlitchedZeus/PokeBank-NX)** | A native Pokémon save manager for Nintendo Switch, with emulator save discovery, staged editing, and generation-aware workflows. Current development focuses on Generations I–V. | Active alpha |
| **[TizenTube NX](https://github.com/GlitchedZeus/Tizentube-NX)** | A controller-first YouTube client for Switch homebrew, focused on guest browsing, a clean interface, and privacy-conscious design. | Pre-alpha |

Both projects are works in progress. Their repositories contain the current scope, development status, and testing notes.

## Open-source contributions

I've contributed to **[PKSE](https://github.com/kiasta/PKSE)**, a Pokémon save editor for Nintendo Switch. Two of my contributions were merged upstream and credited in the [official v1.2.1 release](https://github.com/kiasta/PKSE/releases/tag/v1.2.1):

- **[PR #120 — Left-stick navigation](https://github.com/kiasta/PKSE/pull/120):** D-pad parity, repeat behavior for held input, and more consistent controller navigation.
- **[PR #128 — Pokémon file import/export](https://github.com/kiasta/PKSE/pull/128):** Standalone Pokémon record support, PKHeX-compatible file handling, validation, and safer import/export workflows.

My development fork is [PKSE-Zeus](https://github.com/GlitchedZeus/PKSE-Zeus).
